# Ula-Ulu

A minimal, mobile-first web app for practicing the pronunciation of tricky Ukrainian consonant clusters. Pick a game type, tap the big button, and say the syllable out loud.

## Features

- One big button and one label, nothing else to distract you
- Fullscreen blurred overlay for choosing the game type on every page load
- Nine consonant-cluster game types plus "all"
- Responsive layout for phones and desktops
- Respects `prefers-reduced-motion`

## Game types

| -------- | ---------- |
| `all`    | Усі        |
| `mrl`    | Мрл(і)     |
| `bd`     | Бд(і)      |
| `mn`     | Мн(і)      |
| `kpt`    | Кпт(і)     |
| `shch`   | Шч(і)      |
| `mrktch` | Мрктч(і)   |
| `zd`     | Зд(і)      |
| `zis`    | Зіс(і)     |
